# G ONE AI — Free Mode

This version runs without OpenAI API credits.

## Start
1. Open PowerShell in this folder.
2. Run `npm.cmd install` once.
3. Run `npm.cmd start`.
4. Open http://localhost:3000

`DEMO_MODE=true` means the server does not call the paid OpenAI API. Your API key is not needed.

For automatic start, double-click `run-demo.bat`.

Note: Free Mode uses the built-in local smart brain. Full generative AI answers require an AI API or a separately installed local model.
